**# 🚀 CODE-X AS | Elite Web Artists & Developers

Welcome to the official repository of **CODE-X AS**, a modern, high-performance web development agency portfolio built to showcase creative web solutions, agency services, and team projects.

---

## ✨ Features

* **Responsive Design:** Optimized for all screen sizes (Mobile, Tablet, and Desktop).
* **Modern UI/UX:** Dark-themed aesthetic with interactive micro-animations.
* **Custom Cursor:** Interactive cursor effect for desktop users.
* **Portfolio Showcase:** Highlighted team projects with direct links.
* **Smooth Animations:** Powered by GSAP and ScrollTrigger for a seamless browsing experience.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Libraries:** GSAP (GreenSock), ScrollTrigger, Font Awesome, Devicon
* **Typography & Icons:** Google Fonts (Plus Jakarta Sans)
